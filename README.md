# ki-kartlegging-proto

Prototyperepo for kartlegging av KI-anvendelser i SSB
og utvikling av forvaltningsrammeverk i lys av AI Act
(Forordning 2024/1689).

## Status
Prototypefase. Eies av Thomas Bjørnskau, ikke et SSB-produkt.
Eventuelt produkt overføres til SSB-repo senere.

## Struktur
- `docs/` – notater, beslutninger, metalogg
- `kartlegging/` – skjemaer, intervjuguider, kategorier
- `data/` – kartleggingsdata (se merknad om sensitivitet)
- `app/` – eventuell applikasjon
- `visuelt/` – diagrammer og skisser
- `presentasjoner/` – slides og møtenotater

## Merknad om data
Rådata fra intervjuer lagres ikke i dette repoet.
Se `docs/beslutninger/` for begrunnelse.
